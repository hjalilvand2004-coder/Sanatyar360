# استقرار صنعت‌یار۳۶۰ روی سرور ۱۸۸.۲۱۲.۹۶.۲۳۵ — پورت ۸۰۹۲

هدف: سامانه در آدرس **http://188.212.96.235:8092** در دسترس باشد — هم‌خانواده با
سامانه مادر دانشجویار۳۶۰ (پورت 8086) و مهارت‌یار۳۶۰ (پورت 8090).

از نسخه **v1.0.4 به بعد** پیش‌فرض‌های بسته برای همین استقرار تنظیم شده است:
گوش دادن روی همه کارت‌های شبکه (`0.0.0.0:8092`)، بدون نیاز به هیچ پیکربندی اضافه.

---

## گام ۰ — پیش‌نیازها روی سرور

- بسته ریلیز متناسب با سیستم‌عامل سرور از صفحه ریلیز دانلود شود:
  - ویندوز سرور: `Sanatyar360-portable-windows.zip`
  - لینوکس سرور: `Sanatyar360-portable-linux.tar.gz`
- هیچ پایتون/نیازمندی روی مقصد لازم نیست (بسته مستقل است).
- پورت **8092** در فایروال سرور باز شود (گام مربوط در هر بخش آمده است).

## گام ۱ — استخراج بسته

**ویندوز:** داخل `C:\Sanatyar360` استخراج کنید؛ پوشه `Sanatyar360` شامل `Sanatyar360.exe` است.

**لینوکس:**
```bash
sudo mkdir -p /opt && cd /opt
sudo tar xzf Sanatyar360-portable-linux.tar.gz     # → /opt/Sanatyar360
sudo chmod +x /opt/Sanatyar360/Sanatyar360
```

## گام ۲ — اجرا روی پورت 8092 (روی همه کارت‌های شبکه)

**ویندوز:** اجرای `Sanatyar360.exe` کافی است (پیش‌فرض همان 0.0.0.0:8092 است).
اگر خواستید در پس‌زمینه/پس از ری‌بوت هم بالا بماند، به‌صورت سرویس نصب کنید یا
یک میان‌بر با آرگومان `--no-browser` بسازید.

**لینوکس (سرویس دائم):**
```bash
sudo cp portable/sanatyar360.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now sanatyar360
journalctl -u sanatyar360 -f        # پیگیری لاگ
```

**باز بودن پورت در فایروال:**

```bash
# لینوکس (firewalld — رایج روی سرورهای ایرانی)
sudo firewall-cmd --permanent --add-port=8092/tcp && sudo firewall-cmd --reload
# یا ufw:
sudo ufw allow 8092/tcp
```
```powershell
# ویندوز سرور
netsh advfirewall firewall add rule name="Sanatyar360 8092" dir=in action=allow protocol=TCP localport=8092
```
اگر سرور پشت میکروتیک/NAT است، DNAT پورت 8092 به سرور اضافه شود.

## گام ۳ — بررسی سلامت

```bash
curl http://188.212.96.235:8092/api/v1/health
# {"status":"ok","service":"uiis-api","version":"v1"}
curl http://188.212.96.235:8092/            # رابط وب فارسی
```
در اجرای اول، داده نمونه ساخته می‌شود (۱۰ تا ۳۰ ثانیه). حساب‌های نمونه رمز یکسان: `uiis1234`

## گام ۴ — ثبت در پنل «مدیریت سامانه‌ها»ی دانشجویار۳۶۰ (SSO)

| فیلد پنل مادر | مقدار |
|---|---|
| نام سامانه | صنعت‌یار۳۶۰ |
| کلید سامانه (appKey) | `sanatyar` |
| Client ID | `sanatyar360` |
| **آدرس ورود سامانه (نقطه شروع OIDC)** | `http://188.212.96.235:8092/api/v1/auth/sso/login` |

- آدرس callback به‌صورت خودکار از همان دامنه‌ای که کاربر وارد می‌کند ساخته می‌شود؛
  فقط اگر پشت پراکسی هستید، هنگام اجرا `--public-url http://188.212.96.235:8092` بدهید.
- Client Secret صادرشده از پنل مادر را هنگام اجرا با `SSO_CLIENT_SECRET=...` معرفی کنید.

## گام ۵ — یکپارچگی با مهارت‌یار۳۶۰ (پیش‌فرض فعال)

- `MAHARAT_API_URL` پیش‌فرض همان `http://188.212.96.235:8090/api/v1` است؛ چون مهارت‌یار
  روی همان سرور است، ارتباط server-to-server با کمترین تأخیر برقرار می‌شود.
- اگر لازم شد: `MAHARAT_SERVICE_EMAIL` / `MAHARAT_SERVICE_PASSWORD` حساب سرویس مهارت‌یار.
- تست: با حساب دانشجو وارد شوید → منوی «مهارت‌یار۳۶۰» → «وضعیت ارتباط» باید **زنده** باشد.

## گام ۶ — پایگاه داده و نگهداشت

- پیش‌فرض SQLite کنار برنامه (`sanatyar360.db`) برای شروع کافی است.
- برای بار واقعی، PostgreSQL: `DATABASE_URL=postgresql+psycopg://user:pass@127.0.0.1:5432/uiis`
- پشتیبان‌گیری شبانه از فایل DB یا `pg_dump` + تست بازیابی (`scripts/backup_restore_test.sh`).
- `--reset-db` همه داده را پاک و داده نمونه می‌سازد — فقط بار اول یا محیط تست.
