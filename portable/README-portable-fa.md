# نسخه پرتیبل صنعت‌یار۳۶۰ — راهنمای اجرا

این نسخه **هیچ نیازی به نصب پایتون، PyCharm یا PostgreSQL** ندارد.
همه‌چیز در پوشه `Sanatyar360` بسته شده است (FastAPI + رابط وب + پایگاه داده SQLite + داده نمونه).

## اجرا

1. بسته را دانلود و **استخراج** کنید — یک پوشه `Sanatyar360` می‌بینید.
2. داخل پوشه، روی `Sanatyar360.exe` (ویندوز) یا `./Sanatyar360` (لینوکس) دوبار کلیک کنید.
3. پس از چند ثانیه مرورگر به‌صورت خودکار باز می‌شود (بار اول ساخت داده نمونه کمی بیشتر طول می‌کشد).

> **اگر ویندوز پیام آبی SmartScreen نشان داد:** دکمه **More info** و سپس **Run anyway** را بزنید.
> این پیام به‌دلیل نبود امضای دیجیتال تجاری است، نه وجود ویروس.

> **نکته:** فایل `Sanatyar360.exe` و پوشه `_internal` باید کنار هم بمانند — همه پوشه را منتقل کنید.

فایل‌هایی که کنار برنامه ساخته می‌شوند:

| فایل | کاربرد |
|---|---|
| `sanatyar360.db` | پایگاه داده SQLite (داده شما — برای انتقال همین فایل را کپی کنید) |
| `.jwt_secret` | کلید امضای توکن (یک‌بار خودکار ساخته می‌شود) |
| `sanatyar360.log` | ثبت رویدادها — **در بروز هر مشکل اول این فایل را ببینید** |
| `uploads/` | پیوست‌ها |

## عیب‌یابی سریع

| علامت | علت احتمالی | راهکار |
|---|---|---|
| صفحه وب باز نمی‌شود | سرور هنوز آماده نشده یا پورت اشغال بوده | آدرس چاپ‌شده در پنجره سیاه برنامه را دستی باز کنید؛ برنامه اگر پورت اشغال باشد پورت آزاد بعدی را برمی‌دارد |
| پنجره سیاه فوری بسته می‌شود | خطای شروع | فایل `sanatyar360.log` را باز کنید — جزئیات خطا آنجا است و پنجره در حالت خطا باز می‌ماند |
| پیام SmartScreen / آنتی‌ویروس | بدون امضای تجاری | More info ← Run anyway؛ در آنتی‌ویروس استثنا تعریف کنید |
| صفحه سفید یا بدون استایل | پوشه `_internal` جدا از exe شده | همه پوشه `Sanatyar360` را یک‌جا نگه دارید |

## گزینه‌های خط فرمان

```
Sanatyar360.exe --port 8092          # پورت (پیش‌فرض 8092؛ اگر اشغال بود اولین آزاد بعدی)
Sanatyar360.exe --host 0.0.0.0       # دسترسی از دیگر رایانه‌های شبکه
Sanatyar360.exe --no-browser         # باز نکردن مرورگر
Sanatyar360.exe --reset-db           # بازنشانی به داده نمونه اولیه
```

## ورود به سامانه

- **ورود یکپارچه (SSO)**: دکمه نارنجی «ورود یکپارچه با حساب دانشجو۳۶۰» — جریان کامل OIDC با Client ID `sanatyar360` و کلید سامانه `sanatyar`.
  - در نسخه پرتیبل، چون سامانه مادر در دسترس نیست، **شبیه‌ساز داخلی** با همان جریان اجرا می‌شود.
  - در استقرار واقعی این متغیرها را قبل از اجرا ست کنید:
    ```
    set SSO_AUTH_URL=http://188.212.96.235:8086/oidc/auth
    set SSO_TOKEN_URL=http://188.212.96.235:8086/oidc/token
    set SSO_CLIENT_ID=sanatyar360
    set SSO_CLIENT_SECRET=...
    set SSO_PUBLIC_BASE_URL=http://188.212.96.235:8092
    ```
  - و آدرس `http://188.212.96.235:8092/api/v1/auth/sso/login` را در پنل «مدیریت سامانه‌ها»ی دانشجو۳۶۰ به‌عنوان **آدرس ورود** ثبت کنید.
  - نقش‌های مادر مثل `sanatyar.admin` / `sanatyar.rep` / `sanatyar.student` با `SSO_ROLE_MAP` به نقش‌های سامانه نگاشت می‌شوند.
- **ورود محلی**: حساب‌های نمونه با رمز `uiis1234` (مثلاً `cio@nav.ac.ir`).

## نحوه ساخت نسخه پرتیبل (برای توسعه‌دهندگان)

```bash
cd frontend && npm install && npx vite build
pip install -r portable/requirements-portable.txt
pyinstaller portable/sanatyar360.spec --distpath dist_portable
```

خروجی: پوشه `dist_portable/Sanatyar360/` — بسته مستقل (~۵۶MB شامل `_internal`).
ساخت خودکار ویندوز/لینوکس با GitHub Actions انجام می‌شود؛ **هر نسخه قبل از انتشار در خود CI اجرا و تست سلامت می‌شود**
(smoke test در `.github/workflows/build-portable.yml`) و فقط اگر اجرا موفق بود ریلیز منتشر می‌شود.
بعد از push یک تگ مثل `v1.0.1`، فایل‌های آماده دانلود در GitHub Release قرار می‌گیرد.
