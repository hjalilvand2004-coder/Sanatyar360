# صنعت‌یار۳۶۰ | Sanatyar360

**اتصال دانشجو به صنعت — زیرسیستم دانشجو۳۶۰**

بستر مدیریت چرخه تعامل دانشگاه و صنعت:
**ثبت مسئله صنعتی ← بررسی و انتشار ← شناسایی ظرفیت علمی ← پیشنهاد و درخواست همکاری ← تشکیل تیم و توافق ← پیگیری همکاری ← ثبت دستاورد و تحلیل اثر**

مبتنی بر **FastAPI + React (TypeScript) + PostgreSQL/SQLite** — مونولیت ماژولار با موتور تطبیق قواعدی نسخه‌دار، حسابرسی کامل و ورود یکپارچه OIDC.

---

## ✨ امکانات کلیدی

- 🏭 **بازار مسئله صنعت**: ثبت چندمرحله‌ای، چرخه وضعیت کامل با کنترل کیفیت انتشار، نسخه‌بندی، پرسش‌وپاسخ، سطوح محرمانگی
- 🎯 **موتور تطبیق**: قواعدی نسخه‌دار (`rules-v1.0`) با فیلتر سخت‌گیرانه + رتبه‌بندی + ثبت دلیل هر پیشنهاد
- 🤝 **همکاری صنعتی**: درخواست/تیم/انتخاب انسانی با ثبت دلیل، پروژه همکاری با نقاط عطف، خروجی و پذیرش فقط توسط صنعت
- 📈 **تحلیل‌ها**: تقاضای مهارت با منبع و زمان به‌روزرسانی، شبکه همکاری قابل ردیابی به پروژه واقعی، شاخص‌های اثر
- 💡 **تجاری‌سازی**: غربالگری فرصت با تفکیک ادعای صریح/استنباط و ارزیابی متخصص الزامی
- 🔐 **ورود یکپارچه SSO**: جریان OIDC با سامانه مادر دانشجو۳۶۰ (Client ID: `sanatyar360`، appKey: `sanatyar`)
- 🧾 **حسابرسی**: همه عملیات حساس با عامل، زمان، موضوع و IP
- 🇮🇷 رابط فارسی RTL با فونت وزیرمتن، تاریخ شمسی، تم تیره گلس‌مورفیسم

## 🚀 اجرا — سه راه

### ۱) نسخه پرتیبل (بدون نیاز به پایتون!)

پوشه مستقل با پایگاه داده SQLite و داده نمونه (بدون نصب هیچ پیش‌نیازی):

```bash
# بعد از استخراج بسته، داخل پوشه Sanatyar360:
Sanatyar360.exe            # ویندوز — دوبار کلیک، مرورگر خودکار باز می‌شود
./Sanatyar360              # لینوکس
```

> اگر SmartScreen پیام داد: More info ← Run anyway. در صورت بروز مشکل `sanatyar360.log` کنار برنامه را ببینید.

راهنمای کامل: [portable/README-portable-fa.md](portable/README-portable-fa.md)
فایل‌های آماده: از **GitHub Actions** (تب Actions → آخرین اجرا → Artifacts) یا از **Releases** (با push تگ) دانلود کنید.

### ۲) Docker Compose (سرور — پیشنهادی برای استقرار)

```bash
cd deploy
cp .env.example .env   # رمزها را عوض کنید
docker compose up -d --build   # سرویس روی پورت 8092
```

راهنمای کامل استقرار روی سرور: [deploy/README-fa.md](deploy/README-fa.md)

### ۳) اجرای توسعه

```bash
# پایگاه داده PostgreSQL را با DATABASE_URL معرفی کنید
cd backend && pip install -r requirements.txt
python seed.py            # داده نمونه
uvicorn app.main:app --port 8092

cd frontend && npm install && npx vite build   # یا npm run dev
```

## 🔐 ورود یکپارچه (SSO)

طبق پنل «مدیریت سامانه‌ها»ی دانشجو۳۶۰:

| پارامتر | مقدار |
|---|---|
| نام سامانه | صنعت‌یار۳۶۰ |
| کلید سامانه (appKey) | `sanatyar` |
| Client ID در SSO | `sanatyar360` |
| **آدرس ورود (نقطه شروع OIDC)** | `http://<آدرس-سامانه>:8092/api/v1/auth/sso/login` |

- نقش‌های مادر (مثل `sanatyar.admin`, `sanatyar.rep`, `sanatyar.student`) با `SSO_ROLE_MAP` به نقش‌های محلی نگاشت می‌شوند.
- بدون سامانه مادر، **شبیه‌ساز داخلی** با همان جریان برای تست اجرا می‌شود.
- متغیرها: `SSO_AUTH_URL`, `SSO_TOKEN_URL`, `SSO_USERINFO_URL`, `SSO_CLIENT_SECRET`, `SSO_PUBLIC_BASE_URL`.

حساب‌های نمونه ورود محلی (رمز همه `uiis1234`): `cio@nav.ac.ir`، `rep@pastechno.ir`، `st1@nav.ac.ir`، `prof.karimi@nav.ac.ir`، `comm@nav.ac.ir`، `sysadmin@uiis-system.ir`

## 🧩 یکپارچگی با مهارت‌یار۳۶۰ (اکوسیستم دانشجویار۳۶۰)

صنعت‌یار۳۶۰ با زیرسیستم مهارت‌یار۳۶۰ (`http://188.212.96.235:8090`) در یک نظام هماهنگ ارتباط تنگاتنگ دارد:

| سرویس واکشی‌شده از مهارت‌یار | کاربرد در صنعت‌یار |
|---|---|
| واژه‌نامه مهارت (کد، نام فارسی/انگلیسی، مترادف‌ها، دسته) | تطبیق معنایی مهارت‌های مسئله‌های صنعتی با پروفایل دانشجو |
| پروفایل مهارتی تأییدشده (سطح ۰–۱۰۰ + شواهد هر مهارت) | صفحه «مهارت‌یار۳۶۰» + تقویت موتور تطبیق با شواهد معتبر |
| شکاف مهارتی (`skill-gaps`) و تطبیق شغلی (`career-matches`) | پنل «تحلیل شکاف مهارتی» در جزئیات هر مسئله برای دانشجو |
| حساب‌های کاربری (ایمیل → پروفایل) با حساب سرویس | پیوند خودکار پروفایل با رضایت کاربر (`POST /api/v1/maharat/link`) |
| وضعیت/نسخه موتور مهارت‌یار (`/health`) | کارت «یکپارچگی با مهارت‌یار۳۶۰» در تحلیل‌ها |

- APIها: `GET /maharat/status` · `GET /maharat/skills` · `GET /maharat/careers` · `GET /maharat/me` · `POST /maharat/link` · `POST /maharat/link/refresh` · `DELETE /maharat/link` · `GET /maharat/skill-gap/{problem_id}`
- اعتبارنامه مهارت‌یار هرگز ذخیره نمی‌شود؛ فقط سطوح مهارتی و خلاصه شواهد (snapshot) با رضایت کاربر.
- در نبود مهارت‌یار، سامانه آفلاین ادامه می‌دهد (snapshot نمونه با برچسب «نمونه») — تخریب تدریجی، نه شکست.
- متغیرها: `MAHARAT_API_URL` (پیش‌فرض `http://188.212.96.235:8090/api/v1`)، `MAHARAT_SERVICE_EMAIL/PASSWORD`، `MAHARAT_ENABLED`.
- موتور تطبیق (`rules-v1.0`): مهارت‌های تأییدشده مهارت‌یار در پوشش الزامی‌ها شمرده می‌شوند و در شواهد با دلیل ثبت می‌شوند (مثل «مهارت‌یار۳۶۰: «پایتون» تأییدشده با سطح ۸۵/۱۰۰»).

## 🛡 ملاحظات امنیتی

Argon2id برای رمزها، JWT با Secret خارجی، ایزولاسیون سازمانی و سطوح محرمانگی، حداقل‌سازی پروفایل بدون رضایت، اسکن پسوند/اندازه فایل، لیست مجاز پسوند و عدم افشای اطلاعات در پیام خطا. در پروداکشن: HTTPS، محدودسازی CORS، احراز دومرحله‌ای نقش‌های حساس و انتقال فایل‌ها به Object Storage را فعال کنید.
